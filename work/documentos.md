# Documentos

1. En tareas, features, modulos y proyectos hay documentos adjuntos que se almacenan en r2. A partir de ahora se llamarán Archviso en toda la ui y también a nivel dé código.

2. Crea un nuevo tab llamado Documentos pero ahora de forma similar al de Draw, es decir con titulo, breve descripcion y contenido. El contenido será un docmento markdown que se abrirá como actualmente se edita la descripción

3. En los Documentos se debe poder insertar diagramas de los que hay en Draw del mismo proyecto, modulo, featurte o tarea (es decir dentro del mismo scope), por ejemplo una tarea puede hacer referencia a un diagrama del proyecto o del modulo. Se debe insertar una vista previa pero al abrirlo debe mostrarse en el editor del draw que le corresponde.
