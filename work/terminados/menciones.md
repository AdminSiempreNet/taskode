# Menciones

En los comentarios de seguimiento de proyectos, modulos, features y tareas se debe poder hacer menciones de usuarios (@) y de clientes (#). Cuando se haga mención de usuarios se debe generar una notificación in-app para dicho usuario.

Además, en el composer, el icono para agregar emogies, la primera vez que se le hace clic no muestra correctamente el selector de emogies, es necesario hacer clic una segunda vez para que se vea bien.

Las menciones de usuarios y clientes tambien deben poder hacerse en las descripciones de proyectos, modulos, features y tareas y en los documentos.

El selector de usuarios cuando se escribe @ debe ser similar acomo se ven las listas de usuarios en la asignación y en los filtros, es decir con foto, nombre y correo electronico. Ya en el contenido basta con el nombre resaltado con el hover muestra avatar de usuario completo.
