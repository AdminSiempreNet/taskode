# Dashboard

1. Al acceder a la aplicación, ahora se debe dirigir inicialmente a /dashboard.

2. Para usuarios administradores se debe ver un dasboard con las siguientes características

- El dashboard debe estar enfocado a mostrar el avance de los proyectos y de los equipos.
- Debe mostrar avances y puntos que requieren atención en cada proyecto.

3. Para los usuarios miembros se debe ver un dashboard con las sigientes características

- El dashboard debe estar enfocado en los proyectos y tareas en las que el usuario participa como lider o como parte de un equipo.
- Debe mostrar información de las tareas de todos los proyectos pero enfocado al cumplimiento y avance de las tareas.
- Otros aspectos que puedan ayudar al usuario a tener un enfoque prouductivo.

4. Se debe crear dos proyectos más de ejemplo con datos de ejemplo que permitan evaluar bien cada dashboard y se debe asignar tareas a los dos usuarios existentes.

5. Dashboard por proyectos. En el menú lateral ahora debe haber un item llamado Proyectos que muestra la lista de proyectos, con dos opciones en cada item. Editar que navega a la página de edición del proyecto y Dashboard que navega al dashboard del proyecto. Este dashboard tiene el mismo enfoque que el dashboard administrativo pero se enfoca en el proyecto.

6. Desde la pagina de edicioón de cada modulo y feature, el administrador y los lideres verán un botón para navegar al dashboard del módulo o la feature. Con el mismo enfoque del dashboard del proyecto pero para modulo y feature.

7. Se debe lograr un diseño profesional y con métricas relevantes, legibles y bien presentado.
