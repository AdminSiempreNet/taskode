# Clientes

1. Adiciona la forma de gestionar clientes. Datos básicos como Nombre, Ciudad y Departamento. Pon la ruta accesible desde el menú con el nombre Clientes. 

2. El slector de ciudad en la edición de un cliente debe ser un combobox que agrupa las ciudades por departamento.

3. Se requiere que la tarea tenga opcionalmente la forma de relacionar uno o varios clientes.

4. La lista de clientes se debe gestionar a nivel global pero se debe poder crear desde el mismo combobox de búsqueda. 

5. El combobox que muestra la propiedad muestra el nombre del cliente, pero además tiene dos datos adicoinales que son ciudad y departamento que se muestran en texto muted debajo del nombre principal del cliente.

6. Los departamentos y ciudades de colombia deben sembrarse en la base de datos.
