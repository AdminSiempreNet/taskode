# Menciones

En los comentarios de seguimiento de proyectos, modulos, features y tareas se debe poder hacer menciones de usuarios (@) y de clientes (#). Cuando se haga mención de usuarios se debe generar una notificación in-app para dicho usuario.

Además, en el composer, el icono para agregar emogies, la primera vez que se le hace clic no muestra correctamente el selector de emogies, es necesario hacer clic una segunda vez para que se vea bien.
