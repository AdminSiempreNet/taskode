# File storage

1. Se debe implementar almacenamiento de archivos compatible con s3, intercambiable pero con implementación inicial para r2.

2. La feature ahora debe tener una vista dedicada para editar, de forma similar a como está la edición de la tarea. Es decir el panel de comentarios y los tabs de propiedades.

3. La feature ahora tendrá un tab para adjuntar documentos.

4. Las tareas tambien tienen ahora un tab para adjuntar documentos.

5. La feature tiene un nuevo tab para agregar anotaciones. Las anotaciones son textos con titulo y contenido, que se muestran como listas y se editan en un modal, el editor es el mismo que se usa en la descripción de la tarea y de la feature. 

6. De forma similar a la feature, se debe hacer vistas dedidcas para los módulos y para los proyectos, pero en el caso de los módulos se reemplazan las anotaciones por las features, es decir que desde la vista dedicada de un modulo se ve la lista de features y de igual forma desde la vista dedicada de un proyecto se ve la lista de módulos.
