# Edicion de Features, Modulos y Proyectos

Los proyectos, los modulos y las features ahora tambien se deben editar en una vista dedicada con un esquema de diseño similar al de las tareas, es decir, con un sidebar propio a la izquierda y los elementos a la derecha, además tambien incluyen comentarios, así mismo las opciones comunes del sidebar son descripcion, propiedades y documentos.

Los proyectos incluyen un tab con la lista de módulos que navega hacia el módulo corrspondiente.

Los módulos incluyen un tab con la lista de features que navega hacia la feature correspondiente.

Las features incluyen un tab con la lista de tareas que navega hacia la tarea.

Todas los tabs con listas de modulos, features y tareas usan un diseño igual a la vista de lista de las tareas de una feature.

Se deben reutilizar todos los componentes que sean posible, como el editor y el chat de comentarios y otros, todos los que apliquen para ser reutilizados entre los diferentes niveles jerárquicos.
