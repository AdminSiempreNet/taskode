# Draw

Se necesita un tab más para proyectos, modulos, features y tareas para poder incluir diagramas, ya sea mediante excalidraw.

El tab debe mostrar la lista de diagramas con un título, una breve descripción y al barirlo debe poder dentro del área de contenido o abrirlo a pantalla completa (en la misma o en otra pestaña). El diagrama debe quedar almacenado en la base de datos.

Un diagrama se debe poder compartir públicamente, es decir que un usuario con el link (si es publico) pueda ver el diagrama sin tener que ver otra cosa de la aplicación.
