# Clientes

Adiciona la forma de gestionar clientes. Datos básicos como Nombre, Ciudad y Departamento.

Se requiere que la tarea tenga opcionalmente la forma de relacionar uno o varios clientes.

La lista de clientes se debe gestionar a nivel global pero se debe poder crear desde el mismo combobox de búsqueda. 

El combobox que muestra la propiedad muestra el nombre del cliente, pero además tiene dos datos adicoinales que son ciudad y departamento que se muestran en texto muted debajo del nombre principal del cliente.

Los departamentos y ciudades de colombia deben sembrarse en la base de datos.

El slector de ciudad de un cliente debe ser un combobox que agrupa las ciudades por departamento.
