# Multiusuarios

1. Las tareas tienen un usuario responsable directo (por defecto el autor) y pueden tener varios colaboradores, es decir con aquellos a los que se les compartre.
2. Las features tienen un lider (un usuario). 
3. Los módulos tienen un lider (un usuario)
4. El proyecto tiene un lider (un usuario)
5. Solo los dueños de una tarea o los lideres de la feature, del modulo, del proyecto o un administrador pueden reasignar tareas, modulos o features. El administrador puede reasignar lider de proyecto.
6. Todas las vistas ahora deben incluir un filtro por usuario, similar al filtro de estados, con seleccion múltiple.
